# text-shot.iconset

Generated from `text-shot-menubar-template-menu-fixed.svg`.

## Build .icns on macOS

1. Put all `*.png` files in a folder named `text-shot.iconset/`.
2. Run:

    iconutil -c icns text-shot.iconset

This produces `text-shot.icns`.
